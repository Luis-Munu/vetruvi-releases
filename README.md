# Vetruvi – a free Warframe companion

Riven grading and pricing, item flips, world-state alerts and relic reward reading. Runs on your PC. No account.

Download the latest Windows ZIP from [Releases](https://github.com/Luis-Munu/vetruvi-releases/releases/latest). Each ZIP comes with a `.sha256` file. Extract it and run `Start-Vetruvi.ps1`.

Listed prices are asking prices, not sales.

Vetruvi is a fan-made tool, not affiliated with Digital Extremes.
